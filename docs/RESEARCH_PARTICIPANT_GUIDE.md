# Panduan Partisipan Penelitian FoodRec

## Sebelum ikut

Buka `/research` dan baca informasi studi serta dokumen persetujuan yang ditulis penanggung jawab penelitian. Halaman menampilkan tujuan, data yang dikumpulkan, cara penggunaan, kontak, tanggal, retensi, dan penarikan. Jangan melanjutkan jika informasi belum jelas; gunakan kontak yang tersedia.

Partisipasi sukarela. Persetujuan tidak dicentang sebelumnya dan terpisah dari persetujuan akun FoodRec. Akun USER existing tidak otomatis terdaftar sebagai responden. FoodRec tidak menyatakan bahwa studi telah mendapat persetujuan etik atau memenuhi aturan hukum tertentu.

## Memberi rating

Setelah setuju, buka `/research/rate`. Cari nama makanan atau filter kategori/status. Nilai hanya makanan yang pernah kamu coba:

| Nilai | Arti |
| --- | --- |
| 1 | Tidak suka |
| 2 | Kurang suka |
| 3 | Biasa saja |
| 4 | Suka |
| 5 | Sangat suka |

Centang pernyataan pernah mencoba sebelum menyimpan. Kamu boleh melewati makanan yang belum pernah dicoba, berhenti, lalu lanjut di lain waktu. Tidak ada target minimum; kamu dapat menyelesaikan sesi meskipun rating sedikit atau nol. Sesi yang selesai tidak dapat diedit lagi.

Rating penelitian tersimpan terpisah dari Rating aplikasi. Pilihan pengguna lain tidak ditampilkan. Rating penelitian tidak otomatis memengaruhi rekomendasi FoodRec.

## Status dan privasi

`/research` menampilkan status persetujuan, versi dokumen, dan progress. Dataset memakai participant ID pseudonim, bukan User ID, nama, atau email. Namun aplikasi menyimpan relasi privat ke akun agar dapat mengelola consent dan withdrawal; karena itu dataset **pseudonymous, bukan anonymous**.

## Berhenti dan menarik data

Gunakan tombol **Tarik partisipasi penelitian** di `/research`. Setelah permintaan dikirim, rating tidak dapat ditambah/diubah dan tidak masuk ekspor berikutnya. Admin memproses penghapusan rating/riwayat penelitian dan menangani ekspor lama yang terdampak.

Jika dataset pernah diunduh, aplikasi memblokir download ulang salinan server dan meminta Admin mencatat proses revokasi serta pemberitahuan penerima. Aplikasi tidak dapat menjamin salinan yang sudah berada di luar sistem telah terhapus. Hubungi kontak studi untuk pertanyaan atau status withdrawal.

Menutup halaman tanpa menyetujui berarti tidak ikut. Kamu tetap dapat menggunakan katalog dan rating aplikasi biasa.
